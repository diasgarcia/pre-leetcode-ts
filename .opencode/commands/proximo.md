# /proximo

Não avance imediatamente. Siga esta ordem:

1. Leia `PROGRESSO.md`.
2. Verifique se o exercício atual já está aprovado.
3. Caso ainda não esteja aprovado, execute o mesmo fluxo de `/revisar` (verificador → revisor).
4. **Somente** com TYPECHECK, TESTES e REVISAO aprovados, chame `criador-exercicio`.
5. Crie exatamente UM próximo exercício.
6. Atualize `PROGRESSO.md`.
7. Informe o novo arquivo.
8. Pare.

Se o exercício não estiver correto, explique por que não pode avançar.

Nunca pule um exercício.
